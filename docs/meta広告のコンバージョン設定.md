# Meta広告のコンバージョン設定

診断レポートの申し込みを、Meta（Facebook / Instagram）広告のコンバージョンとして
計測するための手順。

## 仕組み

```
/check/ で診断
   ↓ フォーム送信（お名前・会社名・メール）
   ↓ Formspree に送信成功
   ↓ GA4 に generate_lead を送る（送信完了を待つ／最大0.8秒）
/thanks/ へ遷移   ← ここが広告のコンバージョンポイント
```

`/thanks/` は **申し込みに成功した人しか通らないURL** なので、
これを条件にすればコンバージョンを数えられる。

## 1. ピクセルIDを設定する（未設定）

Meta のイベントマネージャでピクセルを作り、IDを `.env` に入れる。

```
PUBLIC_META_PIXEL_ID=1234567890123456
```

Cloudflare Pages 側にも同じ環境変数を登録すること
（Settings → Environment variables → Production / Preview の両方）。

**未設定のあいだは、ピクセルのコードは1行も出力されない。**
広告を出さない時期に無駄なタグを読み込ませないための作りなので、
「タグが無い」と焦らず、まずIDを入れる。

## 2. イベントマネージャで設定する

ピクセルIDを入れると、次の2つが自動で飛ぶ。

| イベント | 発火場所 | 用途 |
| --- | --- | --- |
| `PageView` | 全ページ | 母数・リターゲティング |
| `Lead` | `/thanks/` のみ | **コンバージョン** |

イベントマネージャで `Lead` をそのままコンバージョンに使える。
うまく拾えない場合は「カスタムコンバージョン」を作り、
条件を **URLに `/thanks/` を含む** にすれば同じことができる。

広告セットの「コンバージョンイベント」に `Lead` を指定すると、
Metaが申し込みそうな人に配信を寄せてくれる。

## 3. 確認のしかた

1. Chrome拡張「Meta Pixel Helper」を入れる
2. 本番の `/check/` で実際に診断 → フォーム送信
3. `/thanks/` に着いた時点で Helper に `PageView` と `Lead` が出れば成功

イベントマネージャの「テストイベント」タブでもリアルタイムに確認できる。

## 注意

- `/thanks/` は **noindex** かつ **サイトマップから除外** している。
  検索から直接来られると、申し込んでいない人でコンバージョンが立ってしまうため。
  この2つは外さないこと。
- URLに個人情報（メールアドレス・氏名）は一切載せていない。
  ピクセルにも渡していないので、今後も渡さないこと。
- 広告を止めたら `PUBLIC_META_PIXEL_ID` を空にすれば、タグごと消える。

## GA4との関係

GA4側の本命CVは `/check/` で送っている `generate_lead`。
`/thanks/` のページビューでも同じ数が見られるので、
GA4で目標到達プロセスを作るときはどちらを使ってもよい。

サンクスページから予約に進んだ人は `booking_click`（`location: thanks`）で拾える。
